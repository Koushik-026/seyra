    What do row and bench labels mean?

    Row 1, Bench 2 is the second bench in the first row. The earlier notation 1:2 meant this location; it was never a size or ratio. Likewise, 3:4 meant row 3, bench 4. Each bench has seat A and seat B.

    If a bench is missing in the middle, keep its position and mark it unavailable so later bench numbers do not shift. For a shorter row, choose Different numbers by row and enter its actual length.

    Saving this layout does not select the room for an exam. Check Use this room in the Rooms page afterwards. Layout edits make affected drafts need regeneration; published history keeps its original layout.
